# StilZip Archive Manager

**StilZip** is a lightweight Windows archive manager designed for creating and extracting archives, with native support for the **StilZip `.stz` format**.

## Features

* Create `.stz` archives
* Extract `.stz` archives
* Direct extraction by double-clicking `.stz` files
* Windows file association
* Custom StilZip archive icon
* Lightweight and simple interface

## Download

The latest version of StilZip can be downloaded from the **Releases** section.

**Current version:** `v1.0.0`

## StilZip Format

StilZip uses the `.stz` file extension for its native archive format.

`.stz` archives currently use **TAR + XZ compression**.

## Windows Integration

After installing StilZip, `.stz` files can be associated with StilZip.

You can then:

**Double-click `main.stz` → StilZip → "Extract main.stz?" → Choose location → Extract**
